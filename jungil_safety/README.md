# 정일건설 안전관리 도우미 (JungilSafety.exe)

HPMS **안전·보건 부적합 보고서(현장)** 와 **TBM 보고서** 를 정일건설(협력업체) 측에서
자체 관리하기 위한 Windows 프로그램입니다.
현장: `[I30F] 태안기업도시 기반시설공사[4차]` (메뉴 *설정 > 현장/업체 정보* 에서 변경 가능)

## 실행파일 받기

1. GitHub 저장소 → **Actions** → *정일건설 안전관리 도우미 exe 빌드* → 최근 실행 → 하단 **Artifacts** 의 `JungilSafety-windows` 다운로드
2. 압축을 풀고 `JungilSafety.exe` 실행 (설치 불필요)
   - 처음 실행 시 Windows SmartScreen 경고가 나오면 *추가 정보 → 실행*
3. 자료는 exe 와 같은 폴더의 `jungil_safety.db` 에 저장됩니다. 폴더째 USB/공유폴더로 옮겨 사용 가능

직접 만들려면 PC 에 Python 3.10+ 설치 후 `build_exe.bat` 더블클릭 → `dist\JungilSafety.exe`

## 기능

### 안전·보건 부적합 보고서
- HPMS 와 같은 항목: 보고서 번호 / 발행부서 / 출처 / 작성자 / 발행일 / 조치요구일 / 조치완료 / 수신처 / 발행구분 / 제목 / 결과확인 (+ 위치, 조치내용, 비고)
- 보고서 번호 비우면 `I30F-HSE-NCR-202610-1` 형식 자동 부여 (월별 순번)
- 상태 자동 표시: **진행중(노랑)** / **기한초과(빨강, 조치요구일 경과)** / 완료
- **기한 내 조치율** 자동 계산 (HPMS 화면 우측 상단 값과 동일한 방식)
- *조치완료 처리*: 선택 건 오늘 날짜로 일괄 완료
- 조회조건: 기간 · 상태 · 수신처(기본 "정일건설") · 검색어

### TBM 보고서
- 항목: 현장코드 / PTW 관리번호 / 협력업체명 / 등록일 / 실시일 / 실시구분 (+ 작업내용, 작업반장, 참석인원, 위험요인, 안전대책)
- *복사 등록(오늘)*: 어제 TBM 을 오늘 날짜로 복사해서 빠르게 작성
- *미실시일 확인*: 조회 기간 중 TBM 기록이 없는 날 표시 (일요일 제외)

### 월별 현황
- 월별 부적합 발행 / 조치완료 / 미조치 / 기한초과 / 기한 내 조치율 / TBM 실시일수

### 엑셀
- 각 목록 **엑셀파일** 저장 (기한초과 건 빨간 글씨)
- **엑셀 불러오기**: HPMS 에서 [엑셀파일] 로 받은 목록을 머리글 이름으로 자동 인식해 가져옴
  (부적합: 보고서 번호가 같으면 갱신 / TBM: PTW+실시일 같으면 건너뜀)
- *파일 > HPMS 화면 예시 자료 불러오기*: 2026-10-12 화면의 부적합 19건 · TBM 18건
