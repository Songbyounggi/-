# 덕진천교 3D 솔리드 모델

교량 도면 5개(교량 일반도·받침배치도, 교대 일반도 A1, 교각 구조도 P1, PSC Beam도, 상부 배치도)에서
치수와 받침 좌표를 추출해 교량 전체를 **ACIS 3DSOLID** 로 모델링하고, 일반도(교대 일반도) 모형공간에 넣었다.

## 결과 파일 (`output/`)

| 파일 | 내용 |
|---|---|
| `일반도_3D.dxf` | 원본 일반도(교대 일반도, R2018) + 3D 솔리드 281개. 3D 모델은 도면 시트 오른쪽(x≈140~210 m)에 있다 |
| `덕진천교_3D모델_R2010.dxf` | 3D 솔리드만(R2010, SAT). 위 파일이 안 열릴 때 쓰는 예비 파일 |
| `preview_*.png` | 저장된 솔리드를 다시 읽어 그린 미리보기 |

AutoCAD에서 DXF를 열고 `SAVEAS` 로 DWG로 저장하면 된다. 3D 확인은 `VSCURRENT` → `Shaded`, `-VIEW` → `SWISO` 를 쓴다.

| 3D-상부-슬래브 | 바닥판 폭 20.4m, t=240mm, 곡선 R=210m | 교량 일반도 좌표·STA |

## 좌표

- 측량좌표(X=북, Y=동)를 mm 단위로 바꿔 도면 시트 오른쪽에 배치했다.
  - `x = (Y − 209150)×1000 + 135000`
  - `y = (X − 309030)×1000 + 30000`
  - `z = EL×1000`
- 검증 결과
  - 3점 원 맞춤으로 구한 도로중심선 반경은 R=210.000m로 도면과 같다.
  - 슬래브 끝선이 교대 흉벽 전면(배면에서 0.80m)과 일치한다.

## 가정과 단순화 (도면에 없거나 읽을 수 없던 부분)

- **A2 교대**: 도면이 A1만 있어서 A1 형상을 그대로 쓰고 A2 받침 EL에 맞춰 높이를 정했다(기초 하단 EL 101.039 추정).
- **교각 P1 표고**: 구조도에 EL 표기가 없다. 코핑 상면을 받침 EL − 0.178m(A1에서 구한 받침+받침대 높이)로 맞추고 나머지는 도면 치수를 따랐다.
- 교각 코핑 상면의 받침대 계단은 경사 평면으로 단순화했다. 교각 기초는 말뚝이 없는 직접기초로 보았다.
- 가로보 두께(단부 0.4m, 중간 0.3m)는 가정값이다. 접속슬래브, 거더 단부 블록, 헌치, 철근은 넣지 않았다.
- 곡선부 부재(슬래브·방호벽·포장)와 원형 단면은 평면 다면체 솔리드로 만들었다(곡면 근사).

## 재생성

```bash
pip install ezdxf matplotlib numpy
# DWG -> DXF 는 LibreDWG dwg2dxf 사용
python3 build_bridge_3d.py <일반도.dxf> output/일반도_3D.dxf [3D만.dxf]
python3 preview.py output/일반도_3D.dxf preview.png [elev azim]
```
